# Brief: 하네스별 배포본 빌드

- SSOT: §3, §6 C1·C2·C6
- 작업 항목: M1-6
- 날짜: 2026-11-06

## 무엇을, 왜

`src/`와 `harness/*.json`으로 `dist/<harness>/`를 만든다([ADR-0003](../adr/0003-neutral-capability-tokens.md)). 설치본은 빌드 결과와 항상 같아야 한다(C6). 빌드는 토큰을 남기지 않아야 하고(C1), 매니페스트에는 출처 고지가 있어야 한다(C2).

하네스별 배포 구성은 능력 표의 `package` 절에 둔다. 항목은 매니페스트 위치, 플러그인 이름, 포함 경로, 훅 여부다. oh-my-pi는 Claude 플러그인 형식이지만 이름이 `orcstack-omp`이고 훅이 없다. opencode는 매니페스트가 없다.
