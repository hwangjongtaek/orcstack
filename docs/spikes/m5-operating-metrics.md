## 측정 조건

- 모든 PR은 한 사람(소유자)과 에이전트 한 세션이 하루 안에 만들었다. 사람 리뷰 대기 없이 tier0·tier1 통과 뒤 머지했다. 팀 운영 기준선이 아니라 도구 자체의 기준선이다.
- 데이터 출처: `gh pr list --state merged`의 생성·머지 시각, 이 저장소의 brief와 work-plan 기록.
